# 📚 BiblioPy - Gerenciamento de uma Biblioteca
## 📖 Sobre o projeto

**O BiblioPy nasceu de um problema real:** O controle de uma biblioteca educacional feito de forma manual, o que gera registros inconsistentes, dificuldade para localizar informações e pouca precisão sobre a disponibilidade dos livros.

O projeto informatiza o gerenciamento básico da biblioteca e fornece indicadores que ajudam a coordenação a entender melhor o uso do acervo: quais obras são mais procuradas, quais estudantes utilizam mais a biblioteca e como está a circulação dos materiais.

Ele foi desenvolvido como projeto acadêmico de lógica de programação, aplicando de forma integrada estruturas de dados, algoritmos, modularização e recursividade.

## ✨ Funcionalidades
- 📕 Livros: cadastro e consulta do acervo
- 👤 Usuários: cadastro de estudantes e usuários da biblioteca
- 🔄 Empréstimos e devoluções: controle da movimentação e da disponibilidade de cada livro
- 📊 Relatórios gerenciais: análises sobre o acervo e sobre a circulação dos materiais
- 📈 Indicadores: obras mais procuradas e usuários mais frequentes

## 🧠 Conceitos aplicados
- Estruturas de dados (listas, dicionários, tuplas)
- Estruturas condicionais e de repetição
- Funções e modularização
- Recursividade
- Algoritmos de busca, contagem e ordenação
  
## 🎯 Objetivos de aprendizagem

Desenvolver uma aplicação realista, organizada e funcional, integrando os principais conceitos de lógica de programação estudados na disciplina.
